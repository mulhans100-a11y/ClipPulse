# ClipPulse v0.1.2 Beta

ClipPulse is a local-first desktop video editor for gaming footage and music-led montages. This beta expands the shared editing workflow used by the desktop application, CLI, REST API, and MCP clients.

## Highlights

- Music analysis reports a confidence-bearing beat grid, local tempo changes, downbeats, accents, energy changes, drops, and quieter sections. Montage styles can use those cues when placing reviewed gameplay highlights.
- Gameplay analysis combines motion, audio, and optional Valorant HUD evidence. Results explain their signals and uncertainty; unverified kill-feed changes remain tentative, and manual event corrections are preserved.
- Agents can assemble and revise editable montage timelines, render relevant preview ranges, request structured quality reports, and use bounded, undoable improvements.
- The MCP setup flow can register ClipPulse with Codex or Claude while preserving existing client configuration and restricting access to approved folders.
- The CI release pipeline packages native installers, checks packaged startup and MCP operation on Windows, and attaches SHA-256 checksums, third-party notices, and a CycloneDX SBOM.

## Requirements and limitations

- Install FFmpeg and FFprobe separately. They are not bundled with ClipPulse. The build must include the `drawtext` filter and `libx264` encoder for the documented title and MP4-export paths.
- Music and gameplay analysis is local and heuristic. It provides evidence and confidence, not guaranteed identification of every beat, kill, or clutch. Review the generated edit before publishing it.
- Model weights for optional local visual analysis download on first use; they are not part of the installer or npm SBOM.
- Installers may be unsigned unless the release workflow has the matching signing credentials. Unsigned Windows and macOS downloads can show platform security warnings.
