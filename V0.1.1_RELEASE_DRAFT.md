# ClipPulse v0.1.1 Beta

ClipPulse is a free, local-first desktop video editor for gaming clips and music-led montages. This beta is the first public application release under the ClipPulse name.

## Included

- Electron and React desktop editor with a media library, source viewer, multitrack timeline, inspector, project recovery, and undo/redo.
- Video and audio import, clip trimming and arrangement, visual/audio controls, titles, transitions, keyframes, and masks.
- Local FFmpeg preview and H.264/AAC MP4 export.
- Music beat/energy cues and heuristic gameplay activity cues to help create editable montage variants.
- A shared, versioned editing interface for CLI, loopback REST, and MCP stdio clients.
- Windows, Linux, and macOS release packages, with checksums and an SBOM attached to the release.

## Requirements and beta notes

- Install FFmpeg and FFprobe separately. They are not included with ClipPulse. The FFmpeg build must provide the `drawtext` filter and `libx264` encoder.
- Analysis of music and gameplay is heuristic; review event choices and timing in the editor.
- The Windows x64 package passed the hosted clean-install/start smoke check. Linux and macOS package builds succeeded, but target-machine installation was not verified.
- Installers are unsigned unless the release workflow was configured with signing credentials. Unsigned Windows/macOS packages may show platform warnings.

Choose the matching installer and verify its SHA-256 against the checksum file on the [v0.1.1 release page](https://github.com/mulhans100-a11y/ClipPulse/releases/tag/v0.1.1). See [installation and troubleshooting](INSTALLATION.md) before first launch.
