# ClipPulse v0.1.4 Beta

This beta improves agent-directed montage planning and makes automatic gameplay selection more cautious and explainable.

## Highlights

- Choose all imported project videos, an explicit clip selection, or selected clips with rough source-time ranges. Range selection can be strict or use a bounded flexible lead-in/tail.
- Let montage duration follow the imported music by default, reuse valid analysis caches, and inspect stage-level performance reports.
- Return structured gameplay evidence, confidence, uncertainty, source ranges, and stable errors when eligible highlights are missing. Unverified scene, OCR, audio, or motion cues are not presented as confirmed player kills.
- Preserve manual event corrections and make the selection modes available through the desktop, CLI, REST, and versioned MCP/agent API.
- Use optional imported local reference footage for measured cut cadence; original media remains read-only.
- Normalize release asset filenames before generating SHA-256 manifests.

## Verification

Release verification is recorded in the GitHub Actions run for tag v0.1.4. The current local test run covers Windows only. macOS and Linux must pass their hosted build, test, smoke, and packaging jobs before their packages are considered verified.

## Requirements and limitations

- Install FFmpeg and FFprobe separately; ClipPulse does not bundle them. Verify required FFmpeg filters/encoders using the installation guide.
- Gameplay analysis is local and heuristic. Kill-feed changes are review candidates, not proof that the recording player scored a kill. No formal real-game precision, recall, or F1 is claimed without a complete annotated dataset.
- Preview and montage plans remain editable; inspect the result before publishing a video.
- Installers may be unsigned without configured signing secrets. Unsigned downloads can show operating-system security warnings.
